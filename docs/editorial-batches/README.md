# الدفعة البحثية الأولى — حالة التسليم

## النطاق المصرح به

- 12 موضوعًا: ثلاثة لكل قسم، بنسختين عربية وإنجليزية (24 سجل مقال مستهدف).
- الوجهة التي وافق عليها المستخدم: قاعدة Supabase المتصلة بلوحة `http://localhost:3000`، عبر الحساب الإداري الموجود فقط.
- مسودات حصريًا: `reviewStatus=draft` و`_status=draft`، والوسائط `published=false`. لا تعديل لسجلات قائمة ولا إنشاء حسابات.

## الملفات والحالة الفعلية

- `initial-history-regions.json`: تاريخ الدرعية، تاريخ الحِجر، جدة التاريخية، منطقة الرياض، منطقة عسير، جغرافيا العلا.
- `initial-people-heritage.json`: محمد عبده، حياة سندي، لبنى العليان، العرضة السعودية، زراعة النخيل في السعودية، القهوة العربية.
- يحتوي كل موضوع على النصين، SEO، مراجع وخرائط أدلة وملاحظات مراجعة وصورة موثقة المصدر.
- `scripts/prepare-editorial-batch.mjs` يجمع الدفعة ويفحص التماثل وحدود SEO وينزل الصور ويفك ترميز JPEG بالكامل عبر Sharp. لا يتصل بقاعدة البيانات.
- `.editorial-staging/manifest.json` و12 صورة JPEG خاصة بالتجهيز، مستثناة من Git وغير موجودة تحت `public`. فُحصت حدود 10 MiB و40 مليون بكسل وسُجل SHA-256 والأبعاد لكل أصل.
- تراخيص الصور ومصادرها موثقة في `../asset-licenses.md`. أصل الحِجر القديم ذو التباس النسب غير مستخدم في الدفعة، واستُبدل موضوع القط العسيري لتجنب حقوق الزخرفة غير المحسومة.

## آلية الرفع المنفذة ومرجع الاستئناف

لا تعِد تنفيذ الإنشاء لهذه الدفعة؛ السجلات موجودة ومعرفاتها أعلاه. تُستخدم الخطوات التالية فقط لفهم الآلية أو تسوية فشل لاحق بعد قراءة الحالة الفعلية.

1. تحقق من حساب المدير والوجهة والأقسام والأعداد مجددًا؛ كانت المقالات والوسائط صفرًا في الفحص الأول، وقد تتغير أثناء التوقف.
2. راجع بيانات الدفعة وملاحظاتها. صِغ بيانات CMS من الحقول المحددة فقط، لا ترسل كائن البحث كله.
3. ارفع الصور من الجلسة نفسها إلى `/api/media` كـ multipart (`file` و`_payload`) بنسب العمل والرخصة من manifest، و`published=false`. ثم اقرأ السجل وتحقق من النوع والأبعاد والحقوق والخصوصية.
4. تحقق من عدم وجود كل هوية `(section, slug, locale)` و`(translationKey, locale)` قبل إنشاء الزوج. أنشئ عبر `/api/articles` فقط، بنفس الصورة والمفتاح وروابط المصادر وترتيبها، وبحالة مسودة صريحة. لا تستخدم seed أو اتصال SQL أو access override.
5. سجل معرفات النجاح أولًا بأول. الفشل الجزئي لا يبرر إعادة إنشاء عمياء أو حذف سجلات.
6. اقرأ السجلات للتحقق من جميع الحقول والزوج وSEO والصورة؛ افحص منع الوصول المجهول للصور والمسودات دون نشرها للاختبار.
7. دوّن حصيلة الرفع الفعلية منفصلة عن عدد الملفات المعدة. لا تعتمد المقالات أو الصور آليًا ولا تغيّر `SITE_INDEXABLE`.

## إصلاحات وفحوص

- تمرير نسب ورخص الصور العامة من CMS وإظهار روابط HTTP(S) آمنة في الصفحات والبطاقات مع React escaping.
- ربط حقول SEO الخاصة باللغة بالعنوان والوصف وOpen Graph وTwitter وcanonical وnoIndex؛ الحفاظ على مسارات اللغات وبوابة الفهرسة العامة.
- `npm run lint`: نجح، مع 20 تحذيرًا في ملفات migrations غير المعدلة.
- `npm run typecheck`: نجح.
- `npm run test`: 95 اختبارًا ناجحًا، بلا إخفاقات.
- تحقق إعداد الدفعة: 12 موضوعًا، 3 لكل قسم، تطابق المصفوفات وترتيب المراجع، 12 صورة JPEG مفكوكة الترميز.
- لم يُنفذ build أو E2E أو اختبار إنتاج/S3. اختبارات العرض والخصوصية وحدوية؛ لم تُختبر صفحة عامة بمقال CMS منشور.

## شروط النشر المتبقية

مراجعة بشرية للحقائق والترجمة وحقوق الاستخدام، ثم اعتماد الوسائط والزوج عبر المسار التحريري. تحتفظ ملاحظات كل موضوع بتعارضات المصادر وفشل بعض صفحات اليونسكو وحدود الدليل؛ القهوة العربية تحتاج دعمًا مرجعيًا إضافيًا. صورة محمد عبده منخفضة الدقة ولا تصلح للتكبير المفرط. صورة لبنى العليان تعتمد ترخيص Flickr تاريخيًا موثقًا في Commons ويحتاج قبوله إلى مراجعة حقوق. لا تُعد هذه الدفعة منشورة أو معتمدة أو جاهزة نهائيًا لمجرد نجاح الاختبارات.
