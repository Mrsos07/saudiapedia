# النشر وعرض الحقوق — 2026-09-14

هذا التحديث يحل محل حالات «مسودة/خاصة» في تقارير الرفع السابقة؛ تبقى تلك التقارير سجلًا لمرحلة التجهيز.

- صرّح المستخدم بإتمام المراجعة وطلب نشر الجميع. نُفذ الاعتماد عبر حساب المسؤول المصادق عليه وبآلية CMS العادية؛ ليست هذه شهادة مراجعة بشرية مستقلة من الوكيل.
- نُشرت المقالات 1–30: 15 موضوعًا ثنائي اللغة. أُتيحت الوسائط 1–14 للعامة.
- تحقق الوصول المجهول: 30 سجل مقال معتمد منشور و14 سجل وسائط عامة. طابقت النصوص والمراجع وحقول SEO والهوية قيمها السابقة؛ تغييرات النشر لم تعد كتابة المحتوى.
- أعادت الصور الأربع عشرة HTTP 200 دون جلسة، بصيغة WebP، وفُك ترميزها في المتصفح. بقي noIndex للمقالات وإعداد الفهرسة العام دون تغيير؛ النشر هنا لا يعني فهرسة Google أو نشر الخادم إلى الإنترنت.
- اكتمل فحص صفحة العرضة بالعربية والإنجليزية، مع الصورة وروابط الحقوق. بدأ فحص جميع مسارات المقالات قبل طلب تعديل الحقوق، لكن لم تُسترجع حصيلته النهائية؛ لا يُدّعى اكتمال فحص الصفحات الثلاثين.

## اختصار حقوق الصور

- تفاصيل حقوق صور CMS أصبحت داخل عنصر HTML أصلي `details` مغلق افتراضيًا، بعنوان «حقوق الصورة» / `Image credits`، في المقالات والبطاقات.
- لا حذف أو تعديل لنسب الصور أو تراخيصها أو إشعارات التحويل والقص؛ تبقى التفاصيل والروابط كاملة عند الفتح. لم تُغير سجلات CMS أثناء إصلاح المظهر.
- تحقق المتصفح: فتح وإغلاق باستخدام Enter بالعربية، إظهار الروابط، النص الإنجليزي، وطي حقوق بطاقات المقالات المرتبطة. عند عرض 390 بكسل لا تجاوز أفقي، حتى بعد الفتح.
- lint نجح مع تحذيرات migrations القديمة؛ typecheck نجح؛ 96 اختبار وحدة ناجح. لم يُنفذ build أو اختبار E2E الكامل أو تحقق إنتاج/S3 لهذا التعديل.
