# موسوعة المملكة | Kingdom Encyclopedia

موقع مستقل بالعربية والإنجليزية مبني بـ Next.js وTypeScript وPayload وPostgreSQL، وليس جهة حكومية. المساران العامان `/ar` و`/en`، والإدارة `/admin`.

## الحالة الفعلية

- البيانات الأولية: **30 موضوعًا ثنائي اللغة** (60 مقدمة): 3 دول سعودية، 13 منطقة إدارية، 7 ملوك، شخصيتان، و5 موضوعات تراثية. جميعها `editorial-preview`؛ **صفر مادة معتمدة للنشر**. وجود مصدر لا يعني اكتمال التحقق البشري.
- **150 موضوعًا / 300 صفحة هدف تخطيطي مقترح، وليس محتوى منجزًا**. يلزم التوسع التحريري والتحقق من الوقائع والمراجع والترجمة قبل الإطلاق.
- الخريطة الحالية مخطط حدود عام وروابط للمناطق، وليست مضلعات تفاعلية لحدود المناطق. البحث الأولي تطبيع نصي داخل الذاكرة؛ `pg_trgm` والفهرسة المتقدمة عمل لاحق.
- لا يوجد ادعاء بتنفيذ نشر إنتاجي أو اختبار PostgreSQL/S3 فعلي في هذه المهمة.

## تشغيل محلي

1. استخدم إصدار Node.js المدعوم من الحزم المثبتة (يفضل Node.js 22 LTS)، وثبّت الاعتماديات بـ `npm install` من جذر المشروع.
2. شغّل `npm run dev` وافتح `http://localhost:3000`. لا تحتاج المعاينة العامة إلى قاعدة بيانات.
3. إعداد CMS اختياري: انسخ `.env.example` إلى `.env.local` واملأ القيم محليًا فقط. غياب `DATABASE_URL` أو `PAYLOAD_SECRET` يبقي الواجهة في وضع المعاينة، والإدارة في وضع الإعداد وREST بحالة 503.
4. لإدارة حقيقية جهّز PostgreSQL موجودًا، وسرًا عشوائيًا بطول 32 محرفًا على الأقل، و`CMS_SERVER_URL` للأصل الصحيح. اتبع [دليل CMS](docs/cms.md)؛ لا ترسل الأسرار في المحادثات أو تضعها في Git.
5. احمِ `/admin` و`/api/users/first-register` قبل تهيئة الحساب الأول عبر واجهة الإدارة. بعد تسجيل المسؤول، أنشئ أدوار التحرير والترجمة والمراجعة من Users؛ لا تنشئ الأداة حسابات افتراضية.

**تفعيل CMS يستبدل بيانات العرض الأولية** بأزواج عربية/إنجليزية مكتملة ومتوافقة، معتمدة ومنشورة فقط. `null` يعني غير مهيأ؛ المصفوفة الفارغة تعني CMS مهيأ بلا أزواج مؤهلة. أخطاء الاتصال ليست سببًا للرجوع إلى المعاينة. يشترط التطابق في `translationKey` والقسم والرابط وترتيب الحقائق والفقرات والمصادر والقيم المشتركة. حفظ المسودة يلغي نشرها فورًا؛ التعديل يتطلب إعادة الاعتماد وفق قواعد المراجعة.

## الأوامر والتحقق

هذه واجهة الأوامر المستهدفة للتكامل؛ إضافة السكربتات غير الموجودة في `package.json` مسؤولية مهمة التكامل الرئيسية، ولم يُعدّل ذلك الملف هنا.

| الأمر | الغرض |
| --- | --- |
| `npm run dev` | خادم التطوير |
| `npm run build` / `npm run start` | البناء ثم تشغيل نسخة الإنتاج محليًا |
| `npm run lint` / `npm run typecheck` | فحص الأسلوب والأنواع |
| `npm run test` | اختبارات الوحدات دون قاعدة بيانات |
| `npm run test:e2e` | اختبارات المتصفح بعد إعدادها في مهمة التكامل |
| `npm run cms:seed` | استيراد المسودات عبر `scripts/seed.ts` |
| `npm run cms:generate-types` | توليد أنواع Payload ومراجعة الناتج |
| `npm run cms:migrate:create` / `npm run cms:migrate` | إنشاء ترحيل ومراجعته ثم تطبيق الترحيلات على قاعدة محددة |

المشغل المباشر للوحدات هو `node --import tsx --test tests/unit/*.test.ts`. تستعمل الاختبارات استيرادات نسبية وطلبات Payload وهمية محددة الأنواع؛ تختبر المحتوى والبحث والأدوار والاعتماد والمستخدمين والصور دون قاعدة بيانات. لا تثبت سلامة REST الفعلية أو قيود PostgreSQL أو S3. **لم تُشغّل الاختبارات في مهمة إضافة هذه الملفات**؛ راجع [قائمة الإطلاق](docs/launch-checklist.md).

## استيراد مسودات CMS

شغّل `npm run cms:seed` بعد ربطه بـ `node --import tsx scripts/seed.ts`، وبعد تهيئة المسؤول عبر `/admin`. تحمل الأداة `.env.local` بواسطة `@next/env` قبل استيراد إعداد Payload؛ متغيرات البيئة الموجودة لها الأولوية.

- تستورد اللغتين لكل موضوع، حتى 60 وثيقة جديدة، بمفتاح مشترك `seed:${section}:${slug}`، وكلها `_status=draft` و`reviewStatus=draft`.
- تستخدم مسؤولًا موجودًا فعليًا من قاعدة البيانات، لا هوية مختلقة. استعلام الهوية منخفض المستوى مخصص للأداة المحلية الموثوقة؛ عمليات المقالات تستخدم Local API مع `overrideAccess:false` و`user` المسؤول وتشغّل hooks.
- لا تحدّث ولا تحذف وثائق موجودة، حتى المنشورة أو المحررة. تتجاوز تطابق مفتاح الترجمة/اللغة أو القسم/الرابط/اللغة. أعد تشغيلها بعد فشل جزئي لإضافة المفقود فقط؛ لا تشغّل نسختين متزامنتين. التعارض يحتاج مراجعة بشرية وليس دمجًا تلقائيًا.
- تستورد الحقائق والفقرات والمراجع باللغة المناسبة. لا تنشئ صورًا أو مستخدمين أو موافقات؛ علاقة الصورة غير محددة ويستخدم العرض الصورة البديلة. راجع ملاءمتها ووصفها وحقوقها قبل النشر.
- في `NODE_ENV=production` ترفض العمل إلا مع `ALLOW_SEED_IMPORT=true`. هذه موافقة على إدخال **مسودات تجريبية** وليست تصريح نشر؛ يفضل الاستيراد في بيئة تطوير/مرحلية. لا تطبع الأداة بيانات الدخول أو أخطاء الاتصال الخام، وتغلق Payload في `finally`.

## الحقوق والخصوصية والإطلاق

- خط **Zain إلزامي** للعربية والإنجليزية. تحميل Google Fonts الخارجي يرسل طلبات إلى Google قد تتضمن IP وبيانات المتصفح؛ وضّح ذلك في سياسة الخصوصية واختبر الخط البديل عند الحجب. لا تضف تحميل خط مكررًا.
- توثيق الصور والشعار ومصادرها وتراخيصها في [سجل الأصول](docs/asset-licenses.md): صور Wikimedia Commons بتراخيص CC BY/CC BY-SA، وشعار مبني على مخطط Natural Earth العام. يلزم إظهار الاعتمادات المطلوبة علنًا؛ الشعار ليس شعار الدولة الرسمي ولا خريطة حدود قانونية. راجع تعليقات الصور القديمة في بيانات المعاينة مقابل هذا السجل قبل النشر.
- Flaticon مؤجل حتى التحقق من تراخيص أصول محددة وأسماء مؤلفيها؛ لا أيقونات غير مرخصة ولا مكتبة أيقونات بديلة.
- أبقِ `SITE_INDEXABLE=false` افتراضيًا للمحتوى غير المراجع وبيئات الاختبار. تحقق من تنفيذه فعليًا في robots/metadata/sitemap أثناء تكامل الواجهة، ولا تفعّل الفهرسة قبل اعتماد الإطلاق؛ `noindex` ليس حماية وصول.
- CMS الإنتاجي يتطلب PostgreSQL وHTTPS وS3 خاصًا دائمًا؛ التخزين المحلي للتطوير فقط. الترحيلات والنسخ الاحتياطي لقاعدة البيانات والوسائط واختبار الاستعادة متطلبات إطلاق، وليست خدمات تم تنفيذها.
- راجع [حالة المحتوى](docs/editorial-status.md)، و[تشغيل CMS](docs/cms.md)، و[قائمة الإطلاق](docs/launch-checklist.md). توسيع سياسة التأليف ونسب المواد للمؤلفين والمراجعين الحقيقيين، ومراجع على مستوى الادعاء، وآلية التصحيح وجدول إعادة المراجعة أعمال مطلوبة؛ لا تختلق أسماء أو تواريخ اعتماد.
